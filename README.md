# Assessment Engine

A multi-tenant Assessment SaaS platform for creating, managing and deploying custom assessments.

## Features

* Assessment Builder
* Category Builder
* Question Builder
* Custom Scoring Engine
* AI Question Generation
* AI Report Generation
* Cloudflare R2 Storage
* Railway Deployment
* Custom Domains
* Multi-Tenant Architecture

## Tech Stack

* Next.js 15
* TypeScript
* PostgreSQL
* Prisma
* Railway
* Cloudflare R2

## Status

Phase 1 — Foundation (multi-tenant skeleton, auth, Tenant/Domain/Theme/User).
